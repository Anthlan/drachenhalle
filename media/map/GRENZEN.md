# Manuell bestätigte Gebietsgrenzen

Diese Datei enthält Gebiete, deren Grenzen anhand bestätigter Spielkoordinaten exakt festgelegt wurden.
Die Eckpunkte werden der Reihe nach umlaufen und jeweils als `X,Y` angegeben. Die Kartenfläche reicht intern von `0,0` bis `1000,1000`; die sichtbaren Spielkoordinaten reichen weiterhin von `1,1` unten links bis `999,999` oben rechts. Die Werte beschreiben Rasterkanten: Eine Ecke zwischen den Feldern X 83/84 und Y 86/87 wird als `83,86` notiert.
