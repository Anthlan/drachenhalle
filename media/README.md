# Medien

Dieser Bereich enthält veröffentlichte, überwiegend sprachneutrale Dateien:

- `alliance`: aktuelle Allianz-Grafiken
- `archive`: historische und ersetzte Medien
- `gallery`: Avatare, Charaktermodelle, Chat- und Reaktionsbilder
- `knowledge`: Grafiken zu Tipps, Events und Ankündigungen
- `map`: Kartenquellen und Masken

Sprachabhängige Wissensgrafiken liegen beim jeweiligen Sprachinhalt unter `content`. Bauanleitungen und Bild-Prompts gehören nach `guides/image-prompts`.
