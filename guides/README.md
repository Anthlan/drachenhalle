# Bauanleitungen und Redaktionsregeln

- `editorial`: verbindliche Regeln für Inhaltspflege, Benennung und Archivierung
- `image-prompts`: wiederverwendbare Prompts und Herstellungsnotizen für Bilder

Veröffentlichte Texte und Styleguides liegen unter `content`; technische Systemdokumentation liegt unter `docs`.
