# Archive

This folder preserves replaced, outdated or historically relevant content. Earlier versions remain traceable without overloading active working areas.

Archived files should retain their previous names or be clearly labeled with the reason and date of archiving.

## Naming rules

- The original filename is generally retained so its origin and earlier references remain traceable.
- If an archived version with the same name already exists, prefix the archive date as `YYYY_MM_DD_`.
- Suffixes such as `final`, `final2`, `neu`, `neu_neu` or `Kopie` are not newly assigned.
- Extensions are lowercase. `README.md` is exempt from retaining the original name.
