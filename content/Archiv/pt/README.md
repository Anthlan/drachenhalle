# Arquivo

Esta pasta preserva conteúdos substituídos, ultrapassados ou historicamente relevantes. As versões anteriores permanecem rastreáveis sem sobrecarregar as áreas de trabalho ativas.

Os arquivos arquivados devem conservar os seus nomes anteriores ou estar claramente rotulados com a razão e a data de arquivalência.

## Regras de nomeação

- O nome do arquivo original é geralmente mantido, de modo que a sua origem e as referências anteriores permanecem rastreáveis.
- Se uma versão arquivada com o mesmo nome já existe, prefixar a data de arquivo como `YYYY_MM_DD_`.
- Sufixos como: `final`, `final2`, `neu`, `neu_neu` ou `Kopie` Não são recém-assignados.
- As extensões são minúsculas. `README.md` é isento de conservar o nome original.
