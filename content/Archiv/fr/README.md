# Archive

Ce dossier conserve des contenus remplacés, périmés ou historiques. Les versions antérieures restent traçables sans surcharger les zones de travail actives.

Les fichiers archivés doivent conserver leur nom antérieur ou être clairement étiquetés avec la raison et la date de l'archivage.

## Règles de désignation

- Le nom original du fichier est généralement conservé de sorte que son origine et les références antérieures restent traçables.
- Si une version archivée avec le même nom existe déjà, préfixez la date d'archive comme `YYYY_MM_DD_`.
- Des suffixes tels que `final`, `final2`, `neu`, `neu_neu` ou `Kopie` ne sont pas nouvellement affectés.
- Les extensions sont en minuscules. `README.md` est exempté de conserver le nom original.
