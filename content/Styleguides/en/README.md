# Style guides

This folder contains the binding design and writing rules for the DIE Dragon Hall. They provide the basis for new avatars, character models, chat and reaction images, and alliance announcements.

Make changes deliberately and record them in a meaningful Git commit, because they affect future content.

## Naming rules

- Image-related style guides are named `DlE-Stil – Topic.md`, for example `DlE-Stil – Avatarbilder.md`.
- Overarching rules are named `DlE – Topic.md`, for example `DlE – Textformatierung.md`.
- Retain the spelling `DlE`, spaces around the dash and a clear German topic title.
- Avoid version suffixes such as `final`, `new` or dates; change the existing guideline and keep changes traceable through Git history.
- `README.md` is exempt from these document naming schemes.
