# Guides de style

Ce dossier contient les règles de conception et d'écriture de la DIE Salle des dragons. Ils fournissent la base de nouveaux avatars, modèles de personnages, images de chat et de réaction, et annonces d'alliance.

Apportez des changements délibérément et enregistrez-les dans un engagement Git significatif, parce qu'ils affectent le contenu futur.

## Règles de désignation

- Les guides de style liés à l'image sont nommés `DlE-Stil – Topic.md`, par exemple `DlE-Stil – Avatarbilder.md`.
- Les règles générales sont nommées `DlE – Topic.md`, par exemple `DlE – Textformatierung.md`.
- Conserver l'orthographe `DlE`, espaces autour du tiret et un titre de sujet allemand clair.
- Évitez les suffixes de version tels que `final`, `new` ou dates; modifier la ligne directrice existante et maintenir les changements traçables dans l'historique de Git.
- `README.md` est exempté de ces schémas de désignation de documents.
