## Règles de désignation

- Modèle & #160;: `Topic_Message.extension`, par exemple `Allianz_Regeln.png`.
- La première partie donne le nom de l'événement ou de l'occasion organisationnelle.
- Ne pas utiliser de préfixes numériques. Les mots ne contiennent pas d'espaces; les umlauts allemands sont écrits comme `Ae`, `Oe`, `Ue` et `ss`.
- Les textes et illustrations principaux associés partagent le même nom de base. D'autres variantes ajoutent un suffixe clair, par exemple `_ChibiAnthlan`.
- Les extensions de fichiers sont minuscules. `README.md` est exempté de ce schéma de nommage de contenu.
