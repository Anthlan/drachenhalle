# Alter ego profiles

Each developed gaming alter ego has its own detailed profile in this folder. The profiles bring together recurring motifs from avatars, character models, chat and reaction images, providing a basis for future character images, compact profiles and stories.

All statements refer solely to the fictional portrayal within the Dragon Knights' visual world. They are not descriptions or judgements of the real people behind the player names.

4. Relationships and role in the ensemble
5. Visual identity and own world
6. Character tensions
7. Compact profile for the website
8. Image direction for the character card
