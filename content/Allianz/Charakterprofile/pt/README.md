# Perfis de alter ego

Cada alter ego de jogo desenvolvido tem o seu próprio perfil detalhado nesta pasta. Os perfis reúnem motivos recorrentes de avatares, modelos de personagens, imagens de bate-papo e reação, fornecendo uma base para imagens futuras de personagem, perfis compactos e histórias.

Todas as declarações se referem exclusivamente ao retrato fictício dentro do mundo visual dos Cavaleiros Dragões. Não são descrições ou julgamentos das pessoas reais por trás dos nomes dos jogadores.

## Estrutura recomendada para outros perfis

1. Material de origem
2. Caráter central
3. Qualidades e motivos recorrentes
4. Relações e papel no conjunto
5. Identidade visual e mundo próprio
6. Tensiões de caráter
7. Profil compacto para o site
8. Direção da imagem para o cartão de caracteres
