# Alter profils ego

Chaque alter ego de jeu développé a son propre profil détaillé dans ce dossier. Les profils regroupent le motif récurrent des avatars, des modèles de personnages, des images de chat et de réaction, fournissant une base pour les images de personnages futurs, compact des profils et des histoires.

Toutes les déclarations se réfèrent uniquement à la représentation fictive dans le monde visuel des Chevaliers du Dragon. Ce ne sont pas des descriptions ou des jugements des vrais gens derrière les noms des joueurs.
