# Профили персонажей

Каждое разработанное игровое альтер-эго имеет в этой папке свой подробный профиль. Профили объединяют повторяющиеся мотивы аватаров, моделей персонажей, изображений чатов и реакций, создавая основу для будущих изображений персонажей, компактных профилей и историй.

Все утверждения относятся исключительно к вымышленному изображению визуального мира Рыцарей-Драконов. Они не являются описаниями или суждениями реальных людей, стоящих за именами игроков.
