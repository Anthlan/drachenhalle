## Naming rules

- Pattern: `Topic_Message.extension`, for example `Allianz_Regeln.png`.
- The first part names the event or organisational occasion. Subsequent words describe the specific content or desired action.
- Do not use numerical prefixes. Words contain no spaces; German umlauts are written as `Ae`, `Oe`, `Ue` and `ss`.
- Related main texts and illustrations share the same base name. Additional variants add a clear suffix, for example `_ChibiAnthlan`.
- File extensions are lowercase. `README.md` is exempt from this content naming scheme.
