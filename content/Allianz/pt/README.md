## Regras de nomeação

- Padrão: `Topic_Message.extension`, por exemplo `Allianz_Regeln.png`.
- A primeira parte designa o evento ou ocasião organizacional. As palavras seguintes descrevem o conteúdo específico ou a ação desejada.
- Não use prefixos numéricos. As palavras não contêm espaços; os umlauts alemães são escritos como `Ae`, `Oe`, `Ue` e `ss`.
- Os textos e ilustrações principais relacionados têm o mesmo nome de base. Variantes adicionais adicionam um sufixo claro, por exemplo `_ChibiAnthlan`.
- As extensões de arquivo são minúsculas. `README.md` é isento deste regime de denominação de conteúdo.
