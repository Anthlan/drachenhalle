# Модели персонажей

Эта папка содержит только необходимые визуальные эталонные модели для повторяющихся персонажей. Они обеспечивают единообразное появление в новых аватарах, сценах и изображениях чата. Готовые сцены относятся к `Galerie/Chatbilder`, независимо от их главного героя.

Назначения серий моделей записываются в [SETINDEX.md](../../../../Galerie/Charaktermodelle/SETINDEX.md). Существующая базовая серия документирует единообразный внешний вид персонажей. Новая серия «Миры индивидуальных персонажей» добавляет к этой основе характерные декорации, реквизит, освещение, цвета и символы.

## Правила именования

- Общее эталонное изображение: `Spielername_Referenzmodell.Dateiendung`.
- Дополнительные виды: `Spielername_Referenzmodell_Ansicht.Dateiendung`, например `Anthlan_Referenzmodell_Ganzkoerper.png`.
- Названа требуемая модель новой мировой серии `Spielername_Modell_Weltserie.Dateiendung`, например `Drachenherz_Modell_Weltserie.png`.
- В дополнительных версиях мировой серии фокус добавляется в виде суффикса, например `Drachenherz_Modell_Weltserie_Ganzkoerper.png`.
- Имена игроков сохраняют подтвержденную капитализацию. В этих именах файлов не используются временные метки или пробелы; расширения файлов указаны строчными буквами.
- Далее следуют задания серии. `SETINDEX.md`; `Weltserie` идентифицирует модели серии M2.
- Каждая модель персонажа должна появиться ровно один раз в `SETINDEX.md`. `README.md` и `SETINDEX.md` освобождены от шаблонов изображений.
