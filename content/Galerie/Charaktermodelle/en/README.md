# Character Models

This folder contains only the required visual reference models for recurring characters. They ensure a consistent appearance in new avatars, scenes and chat images. Finished scenes belong in `Galerie/Chatbilder`, regardless of their main character.

Model-series assignments are recorded in [SETINDEX.md](../../../../Galerie/Charaktermodelle/SETINDEX.md). The existing base series documents the characters’ consistent appearance. The new “Individual Character Worlds” series adds characteristic settings, props, lighting, colours and symbols to this foundation.

## Naming Rules

- General reference image: `Spielername_Referenzmodell.Dateiendung`.
- Additional views: `Spielername_Referenzmodell_Ansicht.Dateiendung`, for example `Anthlan_Referenzmodell_Ganzkoerper.png`.
- The required model of the new world series is named `Spielername_Modell_Weltserie.Dateiendung`, for example `Drachenherz_Modell_Weltserie.png`.
- Additional world-series versions append their focus as a suffix, for example `Drachenherz_Modell_Weltserie_Ganzkoerper.png`.
- Player names preserve confirmed capitalisation. These filenames do not use timestamps or spaces; file extensions are lowercase.
- Series assignments follow `SETINDEX.md`; `Weltserie` identifies M2-series models.
- Every character model must appear exactly once in `SETINDEX.md`. `README.md` and `SETINDEX.md` are exempt from the image patterns.
