# Modelos de caráter

Esta pasta contém apenas os modelos de referência visuais necessários para caracteres recorrentes. Eles garantem uma aparência consistente em novos avatares, cenas e imagens de chat. As cenas acabadas pertencem a `Galerie/Chatbilder`, independentemente do seu personagem principal.

As atribuições de série modelo são registadas em [SETINDEX.md](../../../../Galerie/Charaktermodelle/SETINDEX.md). A série base existente documenta os caracteres’ aparência consistente. O novo “Mundos individuais de caráter” A série acrescenta configurações, acessórios, iluminação, cores e símbolos característicos a esta base.

## Regras de nomeação

- Imagem de referência geral: `Spielername_Referenzmodell.Dateiendung`.
- Observações adicionais: `Spielername_Referenzmodell_Ansicht.Dateiendung`, por exemplo `Anthlan_Referenzmodell_Ganzkoerper.png`.
- O modelo necessário da nova série mundial é chamado `Spielername_Modell_Weltserie.Dateiendung`, por exemplo `Drachenherz_Modell_Weltserie.png`.
- Outras versões da série mundial acrescentam seu foco como sufixo, por exemplo `Drachenherz_Modell_Weltserie_Ganzkoerper.png`.
- Os nomes dos jogadores preservam a capitalização confirmada. Estes nomes de arquivos não usam marcas de tempo ou espaços; extensões de arquivo são em minúsculas.
- Seguem-se as atribuições de série `SETINDEX.md`; `Weltserie` identifica os modelos da série M2.
- Cada modelo de personagem deve aparecer exatamente uma vez em `SETINDEX.md`. `README.md` e `SETINDEX.md` São isentas dos padrões de imagem.
