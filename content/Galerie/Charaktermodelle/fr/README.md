# Modèles de caractères

Ce dossier contient uniquement les modèles de référence visuelle requis pour les caractères récurrents. Ils assurent une apparence cohérente dans les nouveaux avatars, scènes et images de chat. `Galerie/Chatbilder`, quel que soit leur caractère principal.

Les attributions de séries de modèles sont enregistrées dans [MODÈLE](../../../../Galerie/Charaktermodelle/SETINDEX.md). La série de base existante documente les caractères, l'apparence cohérente. Les nouveaux,Individual Character Worlds, série ajoute des paramètres caractéristiques, des accessoires, l'éclairage, des couleurs et des symboles à cette fondation.

## Règles de désignation

- Image de référence générale: `Spielername_Referenzmodell.Dateiendung`.
- Autres points de vue: `Spielername_Referenzmodell_Ansicht.Dateiendung`, par exemple `Anthlan_Referenzmodell_Ganzkoerper.png`.
- Le modèle requis de la nouvelle série mondiale est nommé `Spielername_Modell_Weltserie.Dateiendung`, par exemple `Drachenherz_Modell_Weltserie.png`.
- Des versions de la série mondiale supplémentaires ajoutent leur focus comme un suffixe, par exemple `Drachenherz_Modell_Weltserie_Ganzkoerper.png`.
- Les noms de joueurs préservent les noms d'auteurs confirmés. Ces noms de fichiers n'utilisent pas les horodatages ou les espaces; les extensions de fichiers sont minuscules.
- Les tâches de la série suivent `SETINDEX.md`; `Weltserie` identifie les modèles de la série M2.
- Chaque modèle de caractère doit apparaître exactement une fois dans `SETINDEX.md`. `README.md` et `SETINDEX.md` sont exemptés des modèles d'image.
