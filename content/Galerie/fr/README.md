# Galerie

Cette section contient les collections visuelles affichées dans le site, **Galerie**.

- [Avatars](../Avatare/fr/README.md) – images de profil et d'avatar terminées
- [Modèles de caractères](../Charaktermodelle/fr/README.md) – références requises pour les caractères récurrents
- [Clavardage des images](../Chatbilder/fr/README.md) – images panoramiques, mèmes et nouvelles
- [Images de réaction](../Reaktionsbilder/fr/README.md) – réponses courtes et réutilisables et salutations

Le dossier de la galerie détermine l'utilisation prévue. S1, S2, S3 ou S4 est maintenu conjointement pour le chat et les images de réaction dans [`STILINDEX.md`](../../../Galerie/STILINDEX.md).

Graphiques supplémentaires de `Drachenwissen` et `Styleguides` peut également apparaître dans la galerie web, mais rester stocké avec leur contenu de sujet dans le dépôt.
