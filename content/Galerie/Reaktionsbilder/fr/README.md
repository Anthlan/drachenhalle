# Images de réaction

Ce dossier contient des réponses courtes et réutilisables et des salutations pour le chat d'alliance, comme,Works,,Great,,Sorry, What?,,Morning, ou,Bonne Nuit. Leur message devrait être immédiatement compréhensible sans une scène en cours.

Les images scéniques ou narratives font partie de la [`Galerie/Chatbilder`](../../Chatbilder/fr/README.md), même lorsqu'il est créé dans le style chibi.

## Attribution de style

, Image de réaction, décrit l'utilisation prévue et ne détermine pas le style visuel. S1, S2, S3 ou S4. Leurs tâches requises sont enregistrées à côté des images de chat dans le centre [`Galerie/STILINDEX.md`](../../../../Galerie/STILINDEX.md).

## Règles de désignation

- Modèle & #160;: `YYYY_MM_DD_HHMM_Kurztitel_[Hauptfiguren].Dateiendung`.
- Exemple : `2026_09_25_2331_Passt_Anthlan.png`.
- Le horodatage arrive en premier.
- Le titre abrégé donne un bref nom concis à la réaction réutilisable ou à l'accueil sans espaces.
- Les caractères principaux clairement identifiés sont joints avec des soulignés.
- Les noms de joueurs préservent les noms confirmés; les extensions de fichiers sont minuscules.
- `README.md` est exempté de ce modèle d'image.
