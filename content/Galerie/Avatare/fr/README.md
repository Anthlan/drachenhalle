# Avatars

Ce dossier contient des lecteurs, des images de profil fini et d'avatar. Les fichiers sont destinés à une utilisation directe, pas comme des références générales de caractères.

Les noms de fichiers doivent clairement identifier le lecteur et le temps de création.

Les attributions aux séries d'images sont enregistrées dans [MODÈLE](../../../../Galerie/Avatare/SETINDEX.md). Une série décrit le concept d'image partagée, comme les mondes visuels personnels ou les bâtiments fantaisistes. Les images individuelles et les variantes qui ne peuvent pas encore être clairement assignées restent dans la collection diverse jusqu'à ce qu'une décision délibérée soit Les résultats de l'étude sont présentés dans les pages suivantes.

## Règles de désignation

- Modèle & #160;: `Spielername_YYYY_MM_DD_HHMM.Dateiendung`, par exemple `mysteryZ_2026_08_07_1817.png`.
- Le nom du joueur vient en premier et préserve exactement les imitations utilisées dans le jeu ou dans l'image.
- La date et l'heure viennent de la création d'image et sont toujours écrits en entier avec des soulignés.
- Les extensions de fichiers sont minuscules. `README.md` est exempté de ce modèle d'image.
- Les cessions de séries ne sont pas incluses dans les noms de fichiers, ce qui maintient les noms de fichiers stables si une image est reclassée ultérieurement.
- Chaque avatar doit apparaître exactement une fois dans `SETINDEX.md`. `README.md` et `SETINDEX.md` sont exemptés du modèle d'image.
