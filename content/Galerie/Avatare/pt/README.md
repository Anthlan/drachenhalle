# Avatares

Esta pasta contém jogadores’ imagens de perfil e avatar concluídas. Os arquivos são destinados a utilização directa, não como referências de caracteres gerais.

Os nomes dos arquivos devem identificar claramente o jogador e o tempo de criação.

As atribuições a séries de imagens são gravadas em [SETINDEX.md](../../../../Galerie/Avatare/SETINDEX.md). Uma série descreve o conceito de imagem compartilhada, como mundos visuais pessoais ou edifícios de fantasia. As imagens e as variantes individuais que ainda não podem ser claramente atribuídas permanecem na coleção de várias peças até que seja tomada uma decisão deliberada sobre o seu uso futuro.

## Regras de nomeação

- Padrão: `Spielername_YYYY_MM_DD_HHMM.Dateiendung`, por exemplo `mysteryZ_2026_08_07_1817.png`.
- O nome do jogador vem primeiro e preserva exatamente a capitalização usada no jogo ou na imagem.
- A data e a hora vêm da criação da imagem e são sempre escritas inteiramente com subtítulos.
- As extensões de arquivo são minúsculas. `README.md` é isento deste padrão de imagem.
- As atribuições de série não são incluídas nos nomes de arquivos, mantendo os nomes de arquivos estáveis se uma imagem for posteriormente recategorizada.
- Cada avatar deve aparecer exatamente uma vez `SETINDEX.md`. `README.md` e `SETINDEX.md` São isentas do padrão de imagem.
