# Avatars

This folder contains players’ finished profile and avatar images. The files are intended for direct use, not as general character references.

Filenames should clearly identify the player and creation time.

Assignments to image series are recorded in [SETINDEX.md](../../../../Galerie/Avatare/SETINDEX.md). A series describes the shared image concept, such as personal visual worlds or fantasy buildings. Individual images and variants that cannot yet be clearly assigned remain in the miscellaneous collection until a deliberate decision is made about their future use.

## Naming Rules

- Pattern: `Spielername_YYYY_MM_DD_HHMM.Dateiendung`, for example `mysteryZ_2026_08_07_1817.png`.
- The player name comes first and exactly preserves the capitalisation used in-game or in the image.
- The date and time come from image creation and are always written in full with underscores.
- File extensions are lowercase. `README.md` is exempt from this image pattern.
- Series assignments are not included in filenames, keeping filenames stable if an image is later recategorised.
- Every avatar must appear exactly once in `SETINDEX.md`. `README.md` and `SETINDEX.md` are exempt from the image pattern.
