# Analyses

This folder contains analyses of events, battles, accounts and server development.

The website does not currently list **Analyses** as a separate category. This source folder remains for existing filing guidance and possible later use; public game knowledge currently appears in the numbered tip series.

Analyses document observations, underlying data and conclusions so that strategies or decisions can be derived from them.

## Naming rules

- Pattern: `YYYY_MM_DD_Kurztitel.Extension`, for example `2026_09_23_Serverentwicklung.md`.
- The date identifies the analysis’s data date or completion. The short title uses readable internal capitalization without spaces; German umlauts are written as `Ae`, `Oe`, `Ue` and `ss`.
- Related analysis tables, texts and illustrations receive exactly the same base name.
- Extensions are lowercase. `README.md` is exempt from this content-naming pattern.
