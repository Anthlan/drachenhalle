# Análise

Esta pasta contém análises de eventos, batalhas, contas e desenvolvimento do servidor.

O site não lista atualmente **Análise** como categoria separada. Esta pasta-fonte permanece para orientação de arquivamento existente e eventual uso posterior; conhecimento público do jogo aparece atualmente na série de dicas numeradas.

Analisa as observações, os dados subjacentes e as conclusões, de modo que as estratégias ou as decisões possam ser derivadas a partir delas.

## Regras de nomeação

- Padrão: `YYYY_MM_DD_Kurztitel.Extension`, por exemplo `2026_09_23_Serverentwicklung.md`.
- A data identifica a data ou conclusão dos dados da análise. O título curto usa capitalização interna legível sem espaços; os umlauts alemães são escritos como `Ae`, `Oe`, `Ue` e `ss`.
- As tabelas, textos e ilustrações de análise relacionadas recebem exactamente o mesmo nome de base.
- As extensões são minúsculas. `README.md` é isento deste padrão de nomeação de conteúdo.
