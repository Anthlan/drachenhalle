# Analyses

Ce dossier contient des analyses des événements, batailles, comptes et développement de serveurs.

Le site ne contient pas de liste **Analyses** Ce dossier source reste pour les directives de classement existantes et peut être utilisé ultérieurement; la connaissance des jeux publics apparaît actuellement dans la série de bouts numérotés.

Analyser les observations, les données et les conclusions sous-jacentes afin que les stratégies ou les décisions puissent en découler.

## Règles de désignation

- Modèle & #160;: `YYYY_MM_DD_Kurztitel.Extension`, par exemple `2026_09_23_Serverentwicklung.md`.
- La date identifie l'analyse, la date de données ou l'achèvement. Le titre court utilise la capitalisation interne lisible sans espaces; les umlauts allemands sont écrits comme `Ae`, `Oe`, `Ue` et `ss`.
- Les tableaux d'analyse, textes et illustrations correspondants reçoivent exactement le même nom de base.
- Les extensions sont en minuscules. `README.md` est exempté de ce schéma de dénomination du contenu.
