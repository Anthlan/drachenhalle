# Guides

Ce dossier contient des guides étape par étape plus détaillés sur la mécanique du jeu, les processus et les tâches récurrentes.

Le site n'a pas de **Guides** section. Les connaissances de gameplay public sont maintenues dans la série de bouts numérotés et étiquetées là avec la balise type `Anleitung`. Ce dossier source reste pour les références de dépôt existantes et pour une utilisation future possible.

Entreposez les fichiers texte et image directement ici et connectez-les par le même nom de base.

## Règles de désignation

- Modèle provisoire: `Topic_ShortTitle.extension`, par exemple `AllianzShop_SchrittFuerSchritt.md` et `AllianzShop_SchrittFuerSchritt.png`.
- Sujet et titre court décrivent le guide sans numéro de course. Les mots ne contiennent pas d'espaces; les umlauts allemands sont écrits comme `Ae`, `Oe`, `Ue` et `ss`.
- Les textes, fichiers HTML et illustrations associés doivent partager exactement le même nom de base.
- Une fois que les guides initiaux existent, ce modèle peut être affiné en fonction du contenu réel.
- Les extensions de fichiers sont minuscules. `README.md` est exempté de ce schéma de nommage de contenu.
