# Guides

This folder contains more detailed step-by-step guides to game mechanics, processes and recurring tasks.

The website currently has no separate **Guides** section. Public gameplay knowledge is maintained in the numbered tip series and labelled there with the type tag `Anleitung`. This source folder remains for existing filing references and possible future use.

Store related text and image files directly here and connect them through the same base name.

## Naming rules

- Provisional pattern: `Topic_ShortTitle.extension`, for example `AllianzShop_SchrittFuerSchritt.md` and `AllianzShop_SchrittFuerSchritt.png`.
- Topic and short title describe the guide without a running number. Words contain no spaces; German umlauts are written as `Ae`, `Oe`, `Ue` and `ss`.
- Related texts, HTML files and illustrations must share exactly the same base name.
- Once initial guides exist, this pattern may be refined based on the actual content.
- File extensions are lowercase. `README.md` is exempt from this content naming scheme.
