# Guías

Esta pasta contém guias passo a passo mais detalhadas sobre a mecânica do jogo, os processos e as tarefas recorrentes.

O site atualmente não possui **Guías** secção. Os conhecimentos do jogo público são mantidos na série de pontas numeradas e etiquetados com a etiqueta de tipo `Anleitung`. Esta pasta fonte permanece para referências de arquivamento existentes e possível uso futuro.

Armazenar arquivos de texto e imagem relacionados diretamente aqui e conectá-los através do mesmo nome de base.

## Regras de nomeação

- Padrão provisório: `Topic_ShortTitle.extension`, por exemplo `AllianzShop_SchrittFuerSchritt.md` e `AllianzShop_SchrittFuerSchritt.png`.
- O tema e o título curto descrevem o guia sem um número em execução. As palavras não contêm espaços; os umlauts alemães são escritos como `Ae`, `Oe`, `Ue` e `ss`.
- Os textos, arquivos HTML e ilustrações associados devem ter exactamente o mesmo nome de base.
- Uma vez que existem guias iniciais, este padrão pode ser refinado com base no conteúdo real.
- As extensões de arquivo são minúsculas. `README.md` é isento deste regime de denominação de conteúdo.
