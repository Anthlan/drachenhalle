# Стратегии

В этой папке содержатся тактические выводы, боевые концепции и долгосрочное планирование альянса.

На данный момент на сайте нет отдельного **Стратегии** раздел. Общедоступные сведения об игровом процессе сохраняются в пронумерованных сериях советов и помечаются там тегом типа. `Strategie`. Эта исходная папка остается для существующих ссылок на файлы и возможного использования в будущем.

Контент должен быть практичным, понятным и пригодным для повторного использования для будущих развертываний.

## Правила именования

- Предварительный образец: `Topic_ShortTitle.extension`, например `Waechterkampf_Angriffsplan.md`.
- Тема и краткое название описывают стратегию без порядкового номера. Слова не содержат пробелов; Немецкие умлауты пишутся как `Ae`, `Oe`, `Ue` и `ss`.
- Сопутствующие документы и иллюстрации имеют одно и то же базовое имя.
- Как только будут созданы первоначальные стратегии, эта модель может быть уточнена на основе фактического содержания.
- Расширения файлов записываются строчными буквами. `README.md` освобожден от этой схемы именования контента.
