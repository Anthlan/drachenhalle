# Strategies

This folder contains tactical findings, combat concepts and longer-term alliance planning.

The website currently has no separate **Strategies** section. Public gameplay knowledge is maintained in the numbered tip series and labelled there with the type tag `Strategie`. This source folder remains for existing filing references and possible future use.

Content should be actionable, understandable and reusable for future deployments.

## Naming rules

- Provisional pattern: `Topic_ShortTitle.extension`, for example `Waechterkampf_Angriffsplan.md`.
- Topic and short title describe the strategy without a running number. Words contain no spaces; German umlauts are written as `Ae`, `Oe`, `Ue` and `ss`.
- Related documents and illustrations share exactly the same base name.
- Once initial strategies exist, this pattern may be refined based on the actual content.
- File extensions are lowercase. `README.md` is exempt from this content naming scheme.
