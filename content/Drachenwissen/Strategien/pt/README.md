# Estratégias

Esta pasta contém resultados táticos, conceitos de combate e planejamento de aliança a longo prazo.

O site atualmente não possui **Estratégias** secção. Os conhecimentos do jogo público são mantidos na série de pontas numeradas e etiquetados com a etiqueta de tipo `Strategie`. Esta pasta fonte permanece para referências de arquivamento existentes e possível uso futuro.

O conteúdo deve ser accionable, compreensível e reutilizável para futuras implantações.

## Regras de nomeação

- Padrão provisório: `Topic_ShortTitle.extension`, por exemplo `Waechterkampf_Angriffsplan.md`.
- O tema e o título curto descrevem a estratégia sem um número em execução. As palavras não contêm espaços; os umlauts alemães são escritos como `Ae`, `Oe`, `Ue` e `ss`.
- Documentos e ilustrações relacionados têm exactamente o mesmo nome de base.
- Uma vez que existem estratégias iniciais, este padrão pode ser refinado com base no conteúdo real.
- As extensões de arquivo são minúsculas. `README.md` é isento deste regime de denominação de conteúdo.
