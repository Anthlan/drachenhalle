# Stratégies

Ce dossier contient des constatations tactiques, des concepts de combat et une planification à plus long terme des alliances.

Le site n'a pas de **Stratégies** section. Les connaissances de gameplay public sont maintenues dans la série de bouts numérotés et étiquetées là avec la balise type `Strategie`. Ce dossier source reste pour les références de dépôt existantes et pour une utilisation future possible.

Le contenu devrait être actionnable, compréhensible et réutilisable pour les déploiements futurs.

## Règles de désignation

- Modèle provisoire: `Topic_ShortTitle.extension`, par exemple `Waechterkampf_Angriffsplan.md`.
- Sujet et titre court décrivent la stratégie sans numéro courant. Les mots ne contiennent pas d'espaces; les umlauts allemands sont écrits comme `Ae`, `Oe`, `Ue` et `ss`.
- Les documents et illustrations associés partagent exactement le même nom de base.
- Une fois que les stratégies initiales existent, ce modèle peut être affiné en fonction du contenu réel.
- Les extensions de fichiers sont minuscules. `README.md` est exempté de ce schéma de nommage de contenu.
