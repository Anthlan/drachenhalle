# Eventos

Esta secção reúne eventos de tempo limitado ou pontuais de **Z:Caminho: Redenção**. Cada artigo do evento combina uma breve recomendação com contexto detalhado sobre mecânica, moedas, recompensas e compras opcionais.

Como dicas, os artigos de eventos podem conter versões curtas e completas. A versão curta começa com `## Key points at a glance`; A visão detalhada começa com: `## What is this event guide for?`.

## Nomeamento

```text
Event_XX_Kurztitel.md
Event_XX_Kurztitel.png
```

A PNG com o mesmo nome é a principal ilustração do artigo. Outras imagens recebem sufixos descritivos, tais como `_Budget.png` ou `_Vorratsdepot.png`.

## Confiabilidade

- Os displays atuais no jogo têm prioridade sobre os valores de comparação mais antigos.
- Os preços, as durações restantes e o conteúdo da loja são rotulados com a data da captura.
- As recompensas aleatórias não são apresentadas como retornos garantidos.
- As recomendações de compra comparam sempre os benefícios, as alternativas e o orçamento previamente acordado.
