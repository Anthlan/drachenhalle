# Events

This section collects limited-time or one-off events from **Z:Route: Redemption**. Each event article combines a brief recommendation with detailed context about mechanics, currencies, rewards and optional purchases.

Like tips, event articles may contain short and full versions. The short version starts with `## Key points at a glance`; the detailed view begins with `## What is this event guide for?`.

## Naming

```text
Event_XX_Kurztitel.md
Event_XX_Kurztitel.png
```

The PNG with the same name is the article's main illustration. Further images receive descriptive suffixes, such as `_Budget.png` or `_Vorratsdepot.png`.

## Reliability

- Current in-game displays take priority over older comparison values.
- Prices, remaining durations and shop contents are labelled with the capture date.
- Random rewards are not presented as guaranteed returns.
- Purchase recommendations always compare benefits, alternatives and the budget agreed beforehand.
