# Événements

Cette section recueille des événements ponctuels ou ponctuels **Z:Route: Redemption**Chaque article d'événement combine une brève recommandation avec le contexte détaillé sur la mécanique, les devises, les récompenses et les achats optionnels.

Comme pour les conseils, les articles d'événement peuvent contenir des versions courtes et complètes. `## Key points at a glance`; la vue détaillée commence par `## What is this event guide for?`.

## Désignation des marchandises

```text

```

Le PNG avec le même nom est l'illustration principale de l'article. D'autres images reçoivent des suffixes descriptifs, tels que `_Budget.png` ou `_Vorratsdepot.png`.

## Fiabilité

- Les affichages en jeu actuels prennent la priorité sur les valeurs de comparaison plus anciennes.
- Les prix, les durées restantes et le contenu de l'atelier sont marqués avec la date de capture.
- Les récompenses aléatoires ne sont pas présentées comme des retours garantis.
- Les recommandations d'achat comparent toujours les avantages, les alternatives et le budget convenu au préalable.
