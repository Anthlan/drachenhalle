# Annonces d'événements

Cette section contient des annonces réutilisables pour les prochains événements d'alliance. Chaque article explique l'occasion en détail et se termine par un modèle de copie directement utilisable pour le chat d'alliance.

Les annonces d'événements complètent les deux sections voisines :

- Sous [Calendrier](../../../Termine/fr/README.md), vous pouvez trouver **lorsque** un événement a lieu.
- Sous [Événements](../../Events/fr/README.md), un événement de jeu limité dans le temps est expliqué en détail.
- Ici vous pouvez trouver **ce que nous envoyons à l'alliance immédiatement avant un événement**.

## Règles de désignation

- Modèle & #160;: `Event_Botschaft.Extension`, par exemple `Raubzugkaempfe_Schilde_Hoch.png`.
- La première partie identifie l'événement. Les mots suivants décrivent l'objet ou l'action prévue.
- Les préfixes numériques ne sont pas utilisés. Les mots ne contiennent pas d'espaces; les umlauts allemands sont écrits comme `Ae`, `Oe`, `Ue` et `ss`.
- Les articles et illustrations principales connexes reçoivent exactement le même nom de base.
- Le suffixe `_Eventankuendigung` n'est pas répété parce que le dossier identifie déjà clairement le type de contenu.
- Les extensions sont en minuscules. `README.md` est exempté de ce schéma de dénomination du contenu.
