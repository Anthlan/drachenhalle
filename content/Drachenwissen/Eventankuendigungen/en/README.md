# Event announcements

This section contains reusable announcements for upcoming alliance events. Each article explains the occasion in more detail and ends with a directly usable copy template for alliance chat.

Event announcements complement the two neighboring sections:

- Under [Calendar](../../../Termine/en/README.md), you can find **when** an event takes place.
- Under [Events](../../Events/en/README.md), a time-limited game event is explained in detail.
- Here you can find **what we send to the alliance immediately before an event**.

- [Alliance Ambush: Start prepared](AllianzHinterhalt_Start_Verlueste.md) – preparation, loss management and efficient healing
- [Raid battles: Set shields in time](Raubzugkaempfe_Schilde_Hoch.md) – protection period, shield plan and preparation
- [Zombie Siege: Defend together](ZombieBelagerung_Ablauf_Teilnahme.md) – procedure, participation, withdrawal and support

## Naming rules

- Pattern: `Event_Botschaft.Extension`, for example `Raubzugkaempfe_Schilde_Hoch.png`.
- The first part identifies the event. Following words describe the focus or intended action.
- Numeric prefixes are not used. Words contain no spaces; German umlauts are written as `Ae`, `Oe`, `Ue` and `ss`.
- Related articles and main illustrations receive exactly the same base name.
- The suffix `_Eventankuendigung` is not repeated because the folder already clearly identifies the content type.
- Extensions are lowercase. `README.md` is exempt from this content-naming pattern.
