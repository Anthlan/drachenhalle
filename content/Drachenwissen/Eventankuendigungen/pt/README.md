## Regras de nomeação

- Padrão: `Event_Botschaft.Extension`, por exemplo `Raubzugkaempfe_Schilde_Hoch.png`.
- A primeira parte identifica o evento. As seguintes palavras descrevem o foco ou a ação pretendida.
- Não são utilizados prefixos numéricos. As palavras não contêm espaços; os umlauts alemães são escritos como `Ae`, `Oe`, `Ue` e `ss`.
- Os artigos relacionados e as ilustrações principais recebem exatamente o mesmo nome básico.
- O sufixo `_Eventankuendigung` Não se repete porque a pasta já identifica claramente o tipo de conteúdo.
- As extensões são minúsculas. `README.md` é isento deste padrão de nomeação de conteúdo.
