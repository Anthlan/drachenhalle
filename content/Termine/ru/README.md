# Календарь

Эта папка содержит события, показанные в разделе **Календарь** на сайте. Каждое событие создается как отдельный файл Markdown.

## Имя файла

```text
ГГГГ_ММ_ДД_ShortTitle.md
```

## Шаблон

```markdown
---
title: "Event title"
date: "2026-09-28"
time: "20:00"
end: "21:00"
category: "Alliance event"
location: "Alliance chat"
summary: "Short summary for the calendar overview."
related: "tipp-07-allianz-hinterhalt, eventankuendigung-hinterhalt"
---

Further event information goes here.
```

`time`, `end`, `endDate`, `location` и `related` являются необязательными. `endDate` использует `YYYY-MM-DD` и необходим только для событий, заканчивающихся в более поздний день. Без времени событие отображается как рассчитанное на весь день. Веб-сайт автоматически создает страницу с подробностями и файл календаря для каждого события, готовые для импорта в смартфон, Outlook или Календарь Google.

Под `related`, введите через запятую фрагменты существующих советов, руководств по мероприятиям или объявлений о мероприятиях. Для знакомых повторяющихся событий, таких как «Засада Альянса», «Рейд», «Осада зомби» и «Завоевание столицы», генератор автоматически добавляет соответствующий существующий контент.
