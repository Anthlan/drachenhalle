# Nouvelles

Ce dossier contient des annonces publiées délibérément pour le DIE Page d'accueil Salle des dragons. Chaque annonce est un fichier Markdown séparé commençant par un bloc de métadonnées.

## Nom du fichier

```text
AAAA_MM_DD_Titre court.md
```

## Modèle

```markdown
---
titre: "Titre de l'annonce"
date: "2026-09-24"
catégorie: "Général"
résumé : "Résumé court pour la page d'accueil."
en vedette: faux
---

Le texte de l'annonce complète est ici.
```

`featured: true` met en évidence une annonce sur la page d'accueil. La nouvelle annonce est montrée en premier. Le nom de l'alliance est toujours écrit **DIE** sur le site.
