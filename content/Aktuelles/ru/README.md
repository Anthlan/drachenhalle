# Новости

Эта папка содержит намеренно опубликованные объявления для домашней страницы DIE Зал драконов. Каждое объявление представляет собой отдельный файл Markdown, начинающийся с блока метаданных.

## Имя файла

```text
ГГГГ_ММ_ДД_ShortTitle.md
```

## Шаблон

```markdown
---
title: "Announcement title"
date: "2026-09-24"
category: "General"
summary: "Short summary for the homepage."
featured: false
---

The complete announcement text goes here.
```

`featured: true` выделяет объявление на главной странице. Первым показывается самое новое избранное объявление. Название альянса всегда пишется **DIE** на сайте.
