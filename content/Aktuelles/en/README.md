# News

This folder contains deliberately published announcements for the DIE Dragon Hall homepage. Each announcement is a separate Markdown file beginning with a metadata block.

## Filename

```text
YYYY_MM_DD_ShortTitle.md
```

## Template

```markdown
---
title: "Announcement title"
date: "2026-09-24"
category: "General"
summary: "Short summary for the homepage."
featured: false
---

The complete announcement text goes here.
```

`featured: true` highlights an announcement on the homepage. The newest featured announcement is shown first. The alliance name is always written **DIE** on the website.
