# Notícias

Esta pasta contém anúncios deliberadamente publicados para a página inicial do Salão dos Dragões da DIE. Cada anúncio é um arquivo separado Markdown começando com um bloco de metadados.

## Nome do arquivo

```text
YYYY_MM_DD_ShortTitle.md
```

## Modelo

```markdown
---
title: "Announcement title"
date: "2026-09-24"
category: "General"
summary: "Short summary for the homepage."
featured: false
---

The complete announcement text goes here.
```

`featured: true` salienta um anúncio na página inicial. O anúncio mais recente é exibido primeiro. O nome da aliança está sempre escrito . **DIE** no site.
