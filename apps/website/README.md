# Website-Anwendung

Astro-Anwendung für die Drachenhalle.

- `src`: Seiten, Komponenten, Daten und Sprachkonfiguration
- `scripts`: Generatoren für Dokumente, Termine, News, Galerie, Karte und Übersetzungen
- `public`: veröffentlichte statische Dateien
- `tests`: automatisierte Tests

Die redaktionellen Quellen liegen außerhalb der Anwendung unter `../../content`, gemeinsame Medien unter `../../media`.

```powershell
pnpm install
pnpm dev
pnpm test
pnpm build
```
