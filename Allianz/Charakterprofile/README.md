# Alter-Ego-Profile

In diesem Ordner liegt für jedes ausgearbeitete Spiel-Alter-Ego ein eigenes ausführliches Profil. Die Profile bündeln wiederkehrende Motive aus Avataren, Charaktermodellen, Chat- und Reaktionsbildern und dienen als Grundlage für spätere Personenbilder, Steckbriefe und Geschichten.

Die Aussagen beziehen sich ausschließlich auf die fiktive Darstellung innerhalb der Drachenritter-Bildwelt. Sie sind keine Beschreibung oder Bewertung der realen Personen hinter den Spielernamen.

## Empfohlene Struktur für weitere Profile

1. Materialgrundlage
2. Kernbild der Figur
3. Wiederkehrende Eigenschaften und Motive
4. Beziehungen und Funktion im Ensemble
5. Visuelle Identität und eigene Welt
6. Spannungsfelder der Figur
7. Verdichteter Steckbrief für die Website
8. Bildrichtung für die Personenkarte
